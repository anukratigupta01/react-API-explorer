# React API Explorer

A responsive React application that fetches user data from an API and lets users search, explore, and view detailed user profiles.

## Features

- Fetches user data from the DummyJSON API
- Search users by name or email
- Clear search with a single click
- Displays matching results count
- Loading, error, and empty-result states
- Interactive user cards
- User profile details with photo, address, and company information
- Responsive dark UI with hover effects and animations

## Tech Stack

- React
- JavaScript
- CSS
- Vite
- DummyJSON API
- Git and GitHub

## Getting Started

### Prerequisites

- Node.js
- npm
- Git (optional, for version control)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/anukratigupta01/react-API-explorer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-API-explorer
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## API Used

This project uses the [DummyJSON Users API](https://dummyjson.com/users?limit=30) to fetch sample user information.
